# Outputs — Predicciones del modelo de ventas DSMarket

## Archivos

- **predicciones_futuras.parquet** — predicciones a nivel producto × tienda × fecha para los 28 días siguientes al dataset (25 Apr → 22 May 2016). Entregable principal de la Tarea 3.

- **pred_item_tienda.parquet** — predicciones del período de test (28 Mar → 24 Apr 2016) a nivel producto × tienda. Incluye ventas reales para comparación con el benchmark.

- **resultados_modelo.csv** — mismo contenido que pred_item_tienda.parquet en formato CSV.
