# 🎓 Master Thesis Project — DSMarket

Welcome to the repository of **Lucía, Sandra, Samu, Jorge, and Cristian**! 😎

DSMarket is an end-to-end Machine Learning project built around a retail sales forecasting use case for a fictional supermarket chain operating in New York, Boston, and Philadelphia.

## 📦 What's in this project

- **Exploratory Data Analysis** — sales trends, product popularity, and price variations across cities and stores
- **Clustering** — product and store segmentation
- **Sales Forecasting** — predictive modeling for 28-day sales horizons
- **BI Dashboard** — interactive Power BI report for executive-level insights
- **Store Replenishment Use Case** — applied ML for stock optimization

## 🛠️ Tech stack

Python, pandas, scikit-learn, Power BI, Jupyter Notebooks
